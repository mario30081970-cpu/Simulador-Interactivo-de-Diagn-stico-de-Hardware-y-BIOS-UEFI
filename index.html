Auditoría S.M.A.R.T. — Matriz de Triage (HDD / SSD)
Herramientas recomendadas: CrystalDiskInfo, smartctl. Regla de Oro: si cualquier atributo «Pre-falla» (ID 05, C5, C6) muestra un valor bruto distinto de cero, la estructura lógica está en estado crítico → reemplazo inmediato.
ID 05 — Reallocated Sectors Count Sectores defectuosos que han sido reasignados forzosamente.
ID C5 — Current Pending Sector Sectores altamente inestables esperando reasignación.
ID C6 — Uncorrectable Sector Count Errores graves de lectura/escritura totalmente irreparables.
ID C2 — Temperature Alerta térmica: > 50 °C en HDD / > 70 °C en SSD.
